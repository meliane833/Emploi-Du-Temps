# 🎯 Générateur Automatique d'Emplois du Temps Scolaire

*Générez automatiquement les emplois du temps de votre collège en quelques clics*

## 📋 Description

Application web intuitive qui crée **automatiquement** les emplois du temps pour les collèges (de la 6ème à la 3ème) selon les programmes officiels de l'Éducation nationale.

## ✨ Fonctionnalités

- 🚀 **Génération automatique** des emplois du temps
- 📊 **Optimisation intelligente** (max 3 matières différentes par jour)
- 👨‍🏫 **Gestion simplifiée** des professeurs et classes
- 📥 **Import facile** depuis fichiers Excel
- 📤 **Export complet** en fichiers Excel
- 💾 **Sauvegarde automatique** des données
- 🎯 **Interface intuitive** sans installation requise

## 🎮 Utilisation Rapide

1. **Créer les classes** (6ème, 5ème, 4ème, 3ème)
2. **Ajouter les professeurs** (manuellement ou par import Excel)
3. **Générer les EDT** en un clic
4. **Télécharger** tous les emplois du temps

## 📁 Format d'import Excel

| Nom | Matières |
|-----|----------|
| DUPONT Marie | MATHÉMATIQUES |
| MARTIN Pierre | FRANÇAIS, HISTOIRE-GÉOGRAPHIE |
