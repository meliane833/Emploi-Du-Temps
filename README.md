# Emploi-Du-Temps
Une Application web intuitive créant automatiquement les emplois du temps des collèges (6ème à 3ème). Importez vos professeurs, générez les EDT optimisés avec max 3 matières/jour, et exportez tous les fichiers Excel en un clic. Mémoire intégrée, interface simple, zéro installation. L'outil parfait pour les établissements scolaires ! 📚✨
